# Wallets

## What is a Wallet?

A wallet is a tool for managing cryptocurrency. It stores:
- Private keys
- Public keys/addresses
- Transaction history

## Wallet Types

### Hot Wallets
- Connected to the internet
- Easy to use
- Less secure
- Examples: MetaMask, mobile apps

### Cold Wallets
- Offline storage
- More secure
- Less convenient
- Examples: Hardware wallets, paper wallets

## Wallet Categories

### Software Wallets
- Desktop applications
- Mobile apps
- Web extensions (MetaMask)
- Pros: Convenient, free
- Cons: Vulnerable to malware

### Hardware Wallets
- Physical devices
- Examples: Ledger, Trezor
- Pros: Very secure
- Cons: Cost, less convenient

### Paper Wallets
- Printed private keys
- Pros: Completely offline
- Cons: Easy to lose, no recovery

## Wallet Functions

### Core Operations
- Generate key pairs
- Sign transactions
- View balances
- Send/receive tokens

### Advanced Features
- Multi-signature support
- DApp integration
- Token management
- Network switching

## Security Best Practices

1. **Never share private keys or seed phrases**
2. Use hardware wallets for large amounts
3. Enable 2FA when available
4. Verify addresses before sending
5. Keep backups of seed phrases
6. Use official wallet software only

## Seed Phrases

- 12 or 24 word mnemonic
- Can recover entire wallet
- Must be kept secret and secure
- Write down, never store digitally
