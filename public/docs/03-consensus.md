# Consensus Mechanisms

## What is Consensus?

Consensus is the process by which nodes in a blockchain network agree on the state of the ledger.

## Proof of Work (PoW)

### How it Works
- Miners compete to solve cryptographic puzzles
- First to solve gets to add the block
- Requires significant computational power

### Pros
- Proven security (Bitcoin)
- Decentralized

### Cons
- High energy consumption
- Slow transaction times
- Expensive hardware required

## Proof of Stake (PoS)

### How it Works
- Validators stake cryptocurrency
- Selected to validate based on stake
- Rewards for honest validation

### Pros
- Energy efficient
- Faster transactions
- Lower barriers to entry

### Cons
- Potential centralization
- "Nothing at stake" problem

## Hashgraph Consensus (Hedera)

### How it Works
- Uses gossip protocol
- Virtual voting mechanism
- Asynchronous Byzantine Fault Tolerant (aBFT)

### Pros
- Fast finality
- Fair ordering
- Low fees
- Energy efficient

### Cons
- Permissioned (currently)
- Less decentralized than public chains

## Other Consensus Mechanisms

- **Delegated Proof of Stake (DPoS)**: EOS, Tron
- **Practical Byzantine Fault Tolerance (PBFT)**: Hyperledger
- **Proof of Authority (PoA)**: Private networks
