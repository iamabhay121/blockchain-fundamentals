# Glossary

## A

**Address**: A unique identifier for accounts on a blockchain, derived from a public key.

**Airdrop**: Free distribution of tokens to wallet addresses.

## B

**Block**: A container that holds a batch of transactions and is added to the blockchain.

**Blockchain**: A distributed ledger that maintains a continuously growing list of records.

**Burn**: The permanent removal of tokens from circulation.

## C

**Consensus**: The mechanism by which nodes agree on the state of the blockchain.

**Cryptocurrency**: A digital or virtual currency secured by cryptography.

## D

**DApp**: Decentralized Application - an application that runs on a blockchain.

**DeFi**: Decentralized Finance - financial services built on blockchain.

**Double-spending**: Attempting to spend the same cryptocurrency twice.

## E

**EVM**: Ethereum Virtual Machine - the runtime environment for smart contracts.

**Ethereum**: A decentralized platform for smart contracts and DApps.

## F

**Faucet**: A service that provides free testnet cryptocurrency.

**Fork**: A split in the blockchain, creating two separate chains.

**Fungible**: Interchangeable - one unit is equivalent to another.

## G

**Gas**: The unit of computation on Ethereum, paid for executing transactions.

**Genesis Block**: The first block in a blockchain.

## H

**Hash**: A fixed-size output from a hash function, representing data uniquely.

**Hashgraph**: The consensus algorithm used by Hedera.

**HBAR**: The native cryptocurrency of the Hedera network.

**HTS**: Hedera Token Service - native token service on Hedera.

## I

**Immutable**: Unchangeable - data that cannot be modified once recorded.

## K

**Key Pair**: A private key and its corresponding public key.

## M

**Merkle Tree**: A data structure for efficient data verification.

**Mint**: The creation of new tokens.

## N

**Node**: A computer participating in the blockchain network.

**Nonce**: A number used once in cryptographic operations.

**NFT**: Non-Fungible Token - a unique, non-interchangeable token.

## P

**Private Key**: A secret key used to sign transactions and prove ownership.

**Public Key**: A key derived from a private key, used to verify signatures.

## S

**Smart Contract**: Self-executing code deployed on a blockchain.

**Solidity**: Programming language for writing Ethereum smart contracts.

## T

**Token**: A digital asset on a blockchain.

**Transaction**: An operation that changes the state of the blockchain.

## W

**Wallet**: Software or hardware for managing cryptocurrency and keys.

**Web3**: The third generation of the internet, built on blockchain.
