# Blockchain Basics

## What is a Blockchain?

A blockchain is a distributed ledger technology (DLT) that maintains a continuously growing list of records, called blocks, which are linked and secured using cryptography.

## Key Concepts

### Blocks
- Containers for transactions
- Linked together in chronological order
- Each block contains a hash of the previous block

### Decentralization
- No single point of control
- Distributed across multiple nodes
- Resilience to failures

### Immutability
- Once recorded, data cannot be altered
- Cryptographic hashing ensures integrity
- Consensus mechanisms validate changes

## Types of Blockchains

### Public Blockchains
- Open to anyone
- Examples: Bitcoin, Ethereum
- Permissionless

### Private Blockchains
- Restricted access
- Controlled by a single organization
- Permissioned

### Consortium Blockchains
- Controlled by a group of organizations
- Hybrid approach
- Examples: Hedera Hashgraph

## Common Use Cases

- Cryptocurrencies
- Smart contracts
- Supply chain tracking
- Identity management
- Decentralized finance (DeFi)
