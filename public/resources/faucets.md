# Testnet Faucets

Get free testnet cryptocurrency for development and testing.

## Hedera Testnet

### Official Faucet
- [Hedera Portal](https://portal.hedera.com/) - Official testnet account creation
  - Create account and receive initial testnet HBAR
  - Requires email verification

### Alternative Sources
- [Hedera Discord](https://hedera.com/discord) - Community faucet in #testnet-faucet channel
- [Yamgo](https://yamgo.com/) - May provide testnet HBAR

## Tips for Using Faucets

1. **Rate Limits**: Most faucets have rate limits (e.g., once per 24 hours)
2. **Account Requirements**: Some require social media verification
3. **Minimum Balances**: Keep some testnet tokens for gas fees
4. **Network Selection**: Ensure you're on the correct testnet
5. **Backup Accounts**: Create multiple test accounts if needed

## Best Practices

- Use testnets for all development and testing
- Never use mainnet for testing
- Keep testnet tokens separate from mainnet
- Document which faucets you've used
- Share faucet links with your team

## Troubleshooting

### "Insufficient funds" errors
- Check you're on the correct network
- Verify faucet transaction completed
- Wait for transaction confirmation

### Faucet not working
- Try alternative faucets
- Check faucet status/announcements
- Join community Discord for help

### Account not receiving tokens
- Verify account address is correct
- Check transaction on explorer
- Wait a few minutes for confirmation
