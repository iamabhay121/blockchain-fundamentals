# Development Tools

## Blockchain Explorers

### Hedera
- [HashScan](https://hashscan.io/) - Official Hedera explorer
- [DragonGlass](https://app.dragonglass.me/) - Alternative explorer

### Ethereum
- [Etherscan](https://etherscan.io/) - Mainnet explorer
- [Sepolia Etherscan](https://sepolia.etherscan.io/) - Testnet explorer
- [Blockscout](https://blockscout.com/) - Open-source explorer

## IDEs and Editors

- [Remix IDE](https://remix.ethereum.org/) - Browser-based Solidity IDE
- [VS Code](https://code.visualstudio.com/) - Popular code editor
  - [Solidity Extension](https://marketplace.visualstudio.com/items?itemName=JuanBlanco.solidity)
  - [Hardhat Extension](https://marketplace.visualstudio.com/items?itemName=NomicFoundation.hardhat-solidity)

## Development Frameworks

### Ethereum
- [Hardhat](https://hardhat.org/) - Most popular framework
- [Foundry](https://book.getfoundry.sh/) - Fast, Rust-based
- [Truffle](https://trufflesuite.com/) - Older but still used
- [Brownie](https://eth-brownie.readthedocs.io/) - Python framework

### Hedera
- [Hedera SDK](https://docs.hedera.com/hedera/sdks-and-apis/sdks) - Official SDKs
- [Hedera Smart Contracts](https://docs.hedera.com/hedera/smart-contracts) - Solidity on Hedera

## Testing Tools

- [Hardhat Network](https://hardhat.org/hardhat-network/docs) - Local Ethereum network
- [Ganache](https://trufflesuite.com/ganache/) - Personal blockchain
- [Anvil](https://book.getfoundry.sh/anvil/) - Foundry's local node

## Security Tools

- [Slither](https://github.com/crytic/slither) - Static analysis

- [Mythril](https://github.com/ConsenSys/mythril) - Security analysis
- [Oyente](https://github.com/melonproject/oyente) - Security analyzer
