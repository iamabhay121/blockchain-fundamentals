# Ethereum Resources

## Official Documentation

- [Ethereum.org](https://ethereum.org/) - Main Ethereum website
- [Ethereum Developer Docs](https://ethereum.org/en/developers/docs/) - Complete developer documentation
- [Solidity Documentation](https://docs.soliditylang.org/) - Solidity language reference

## Development Tools

- [Remix IDE](https://remix.ethereum.org/) - Browser-based Solidity IDE
- [Hardhat](https://hardhat.org/) - Ethereum development environment
- [Foundry](https://book.getfoundry.sh/) - Fast, portable toolkit
- [Truffle](https://trufflesuite.com/) - Development framework

## Libraries

- [ethers.js](https://docs.ethers.io/) - Ethereum JavaScript library
- [web3.js](https://web3js.readthedocs.io/) - Ethereum JavaScript API
- [viem](https://viem.sh/) - TypeScript Ethereum library

## Explorers

- [Etherscan](https://etherscan.io/) - Ethereum mainnet explorer
- [Sepolia Etherscan](https://sepolia.etherscan.io/) - Sepolia testnet explorer
- [Blockscout](https://blockscout.com/) - Open-source explorer

- [Sepolia Faucet](https://sepoliafaucet.com/) - Get Sepolia ETH
- [Alchemy Faucet](https://www.alchemy.com/faucets/ethereum-sepolia) - Alchemy faucet
- [Infura](https://www.infura.io/) - Ethereum API and infrastructure

- [MetaMask](https://metamask.io/) - Browser extension wallet
- [Coinbase Wallet](https://www.coinbase.com/wallet) - Mobile and browser wallet

- [CryptoZombies](https://cryptozombies.io/) - Learn Solidity by building games

## Standards

- [ERC-20](https://eips.ethereum.org/EIPS/eip-20) - Fungible token standard
- [ERC-721](https://eips.ethereum.org/EIPS/eip-721) - NFT standard
- [ERC-1155](https://eips.ethereum.org/EIPS/eip-1155) - Multi-token standard
- [EIPs](https://eips.ethereum.org/) - Ethereum Improvement Proposals
