# Blockchain Learning Repository

A comprehensive learning resource for blockchain development, focusing on Hedera, Ethereum, and Solidity.

## 📚 Overview

This repository contains:
- **Documentation**: Core concepts and theory
- **Code Examples**: Working code snippets for common tasks
- **Projects**: Full-featured applications
- **Exercises**: Hands-on practice problems
- **Resources**: Curated links and tools

## 🚀 Quick Start

1. Clone this repository
2. Install dependencies: `npm install`
3. **View documentation in UI**: Run `npm run docs` to open the web-based documentation viewer
4. Or follow the [LEARNING_PATH.md](./LEARNING_PATH.md) guide
5. Start with the basics in `docs/01-blockchain-basics.md`

## 📖 Learning Path

See [LEARNING_PATH.md](./LEARNING_PATH.md) for a structured progression guide.
